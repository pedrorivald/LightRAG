1"""UI customization bundle loading and immutable snapshot (workspace-entry PRD §8). 

2 

3A deployment may point ``UI_TEMPLATES_DIR`` at an external, read-only bundle 

4directory that provides the welcome page / query-empty-state texts, the 

5optional login-page blurb and user-agreement document, the optional copyright 

6line, and brand logos for the WebUI entries, per locale. The server validates the WHOLE 

7bundle at startup and atomically activates it as an immutable in-memory 

8snapshot; request handling never touches the disk again. 

9 

10Trust model (§8.1.1): the bundle is trusted deployment content — the same 

11trust tier as ``.env`` and compose files. Validation here serves structural 

12correctness (diagnosable configuration errors), protection against 

13accidentally reading arbitrary server files through a mistyped path, and 

14deployment diagnosability — it is NOT a threat model against the bundle 

15author. 

16 

17Failure semantics (§8.4): 

18- ``UI_TEMPLATES_DIR`` unset ⇒ no bundle. This is the NORMAL state, not a 

19 degradation: no warning, no snapshot; the frontend renders its own default 

20 content. 

21- ``UI_TEMPLATES_DIR`` set ⇒ the bundle must validate completely or server 

22 startup FAILS (raising :class:`UICustomizationError`). Silently falling 

23 back to default content is exactly the failure mode this forbids: the 

24 operator would believe the customer branding is live while LightRAG 

25 content is shown. This check is fully orthogonal to whether 

26 ``workspace.html`` exists. 

27"""

110def normalize_locale(value: str) -> str: 

111 """BCP 47-style normalization: case only, never shape conversion. 

112 

113 - validates basic format and length; rejects empty values; 

114 - REJECTS the underscore form (``zh_TW``): converting the frontend's 

115 internal ids to hyphens is the frontend's single-throat job (§8.2), 

116 the server only refuses the wrong shape; 

117 - lowercases the language subtag, uppercases 2-letter region subtags, 

118 titlecases 4-letter script subtags. 

119 """ 

120 if not isinstance(value, str) or not value.strip(): 

121 raise ValueError("locale must be a non-empty string") 

122 value = value.strip() 

123 if "_" in value: 

124 raise ValueError( 

125 f"locale {value!r} uses the underscore form; the API accepts only " 

126 "the BCP 47 hyphen form (e.g. zh-TW)" 

127 ) 

128 if len(value) > 35: 

129 raise ValueError(f"locale {value!r} is too long") 

130 subtags = value.split("-") 

131 normalized: list[str] = [] 

132 for index, subtag in enumerate(subtags): 

133 if not _LOCALE_SUBTAG_RE.match(subtag): 

134 raise ValueError(f"locale {value!r} has an invalid subtag {subtag!r}") 

135 if index == 0: 

136 if not subtag.isalpha() or len(subtag) < 2: 

137 raise ValueError(f"locale {value!r} has an invalid language subtag") 

138 normalized.append(subtag.lower()) 

139 elif len(subtag) == 4 and subtag.isalpha(): 

140 normalized.append(subtag.title()) 

141 elif (len(subtag) == 2 and subtag.isalpha()) or ( 141 ↛ 146line 141 didn't jump to line 146 because the condition on line 141 was always true

142 len(subtag) == 3 and subtag.isdigit() 

143 ): 

144 normalized.append(subtag.upper()) 

145 else: 

146 normalized.append(subtag.lower()) 

147 return "-".join(normalized)

150def locale_direction(locale: str) -> str: 

151 """'rtl' / 'ltr' for a BCP 47 locale, from the trusted registry. 

152 

153 An explicit SCRIPT subtag is authoritative and outranks the language, 

154 because saying which script the text is written in is exactly what it is 

155 for: ``ku-Arab`` is right-to-left while plain ``ku`` (Latin by default) 

156 is not, and the same holds for ``az-Arab``, ``pa-Arab``, ``ha-Arab``… 

157 

158 The script's position is DERIVED from the grammar, not assumed:: 

159 

160 langtag = language ["-" script] ["-" region] … 

161 language = 2*3ALPHA ["-" extlang] / 4ALPHA / 5*8ALPHA 

162 extlang = 3ALPHA *2("-" 3ALPHA) 

163 

164 so it follows the language and up to three extlang subtags (``Latn`` is 

165 the THIRD subtag of ``ar-aao-Latn``), and nothing after that. Both bounds 

166 matter: a fixed index misses the extlang form, while scanning for any 

167 4-letter subtag would read an extension's value as a script — and 

168 ``ar-u-nu-latn`` asks for Latin DIGITS in Arabic text while remaining 

169 right-to-left. A 3-ALPHA subtag in that window can only be an extlang: a 

170 region is 2 letters or 3 digits, and a variant is 5-8 characters (or 4 

171 beginning with a digit). 

172 

173 Without a script subtag the language's own default decides. A bundle may 

174 declare any valid BCP 47 locale, so the registry covers every language 

175 CLDR knows to be RTL by default; for anything it still misses (a private 

176 or newly registered code), writing the script subtag is the exact and 

177 always-available escape hatch. 

178 """ 

179 subtags = locale.split("-") 

180 index = 1 

181 while ( 

182 index < len(subtags) 

183 and index <= _MAX_EXTLANG_SUBTAGS 

184 and len(subtags[index]) == 3 

185 and subtags[index].isalpha() 

186 ): 

187 index += 1 

188 script = subtags[index] if index < len(subtags) else "" 

189 if len(script) == 4 and script.isalpha(): 

190 return "rtl" if script.lower() in _RTL_SCRIPT_SUBTAGS else "ltr" 

191 return "rtl" if subtags[0].lower() in _RTL_LANGUAGE_SUBTAGS else "ltr"

235# XML's S production — exactly these four, not `bytes.isspace()` (which also 

236# accepts \v and \f, neither of which XML allows between tokens). 

237_XML_SPACE = frozenset(b" \t\r\n") 

238_QUOTE_BYTES = frozenset(b"\"'") 

239_GT = 0x3E # > 

240_SLASH = 0x2F # / 

241_EQUALS = 0x3D # = 

242_LT = 0x3C # < 

243_AMP = 0x26 # & 

244_HEX_DIGITS = frozenset(b"0123456789abcdefABCDEF") 

245# What a reference's name cannot span: the delimiters that would mean the 

246# reference was never terminated in the first place. 

247_REFERENCE_NAME_END = frozenset(b" \t\r\n<&;\"'") 

248_LBRACKET = 0x5B # [ 

249_RBRACKET = 0x5D # ]

251# own characters (XML's NameChar is a large Unicode set, and a name's validity 

252# is not what decides whether a root element is there); what matters is that 

253# the name stops where the grammar says the next token begins. 

254_ATTR_NAME_END = frozenset(b" \t\r\n=></\"'")

257def _end_of_markup_declaration(content: bytes, index: int) -> int | None: 

258 """Index just past a ``<!…>`` declaration whose body starts at ``index``. 

259 

260 Used for the DOCTYPE (and any other top-level ``<!`` node). Its end is the 

261 first ``>`` that is BOTH outside a literal and outside the internal 

262 subset, because everything else can legitimately contain one: 

263 

264 * ``<!DOCTYPE svg SYSTEM "a>b.dtd">`` — inside a system literal; 

265 * ``<!DOCTYPE svg [<!ENTITY x "foo">]>`` — inside the subset, which 

266 Illustrator has emitted for years. 

267 

268 Sub-nodes are skipped WHOLE rather than scanned for quotes: a comment in 

269 the subset may hold an apostrophe (``<!-- don't -->``) that quote tracking 

270 would read as an unterminated literal, rejecting a valid file. 

271 

272 Returns None when the declaration never ends. 

273 """ 

274 depth = 0 

275 i = index 

276 n = len(content) 

277 while i < n: 

278 byte = content[i] 

279 if byte in _QUOTE_BYTES: 

280 end = content.find(content[i : i + 1], i + 1) 

281 if end == -1: 281 ↛ 282line 281 didn't jump to line 282 because the condition on line 281 was never true

282 return None 

283 i = end + 1 

284 elif content.startswith(b"<!--", i): 

285 end = content.find(b"-->", i + 4) 

286 if end == -1: 286 ↛ 287line 286 didn't jump to line 287 because the condition on line 286 was never true

287 return None 

288 i = end + 3 

289 elif content.startswith(b"<?", i): 289 ↛ 290line 289 didn't jump to line 290 because the condition on line 289 was never true

290 end = content.find(b"?>", i + 2) 

291 if end == -1: 

292 return None 

293 i = end + 2 

294 elif byte == _LBRACKET: 

295 depth += 1 

296 i += 1 

297 elif byte == _RBRACKET: 

298 depth = max(depth - 1, 0) 

299 i += 1 

300 elif byte == _GT and depth == 0: 

301 return i + 1 

302 else: 

303 i += 1 

304 return None

307def _is_reference_body(body: bytes) -> bool: 

308 """Whether ``&`` + ``body`` + ``;`` is a syntactically valid reference:: 

309 

310 CharRef ::= '&#' [0-9]+ ';' | '&#x' [0-9a-fA-F]+ ';' 

311 EntityRef ::= '&' Name ';' 

312 

313 The entity NAME is not checked against XML's NameChar set, and the entity 

314 is not required to be DECLARED — an internal subset may define its own 

315 (``&ns_extend;`` in Illustrator output) and resolving one is the 

316 renderer's business, not this sniffer's. 

317 """ 

318 if body[:2].lower() == b"#x": 

319 digits = body[2:] 

320 return bool(digits) and all(byte in _HEX_DIGITS for byte in digits) 

321 if body[:1] == b"#": 

322 return body[1:].isdigit() 

323 return bool(body) and not any(byte in _REFERENCE_NAME_END for byte in body)

326def _is_attribute_value(content: bytes, start: int, end: int) -> bool: 

327 """Whether ``content[start:end]`` is a legal ``AttValue`` body:: 

328 

329 AttValue ::= '"' ([^<&"] | Reference)* '"' (and the same with "'") 

330 

331 The delimiting quote is excluded by construction — ``end`` is where it 

332 was found — which leaves two rules. ``<`` is forbidden outright, and a 

333 ``&`` is forbidden UNLESS it opens a reference: a bare one makes 

334 ``<svg title="&">`` a fatal error, so it is a file no renderer will draw, 

335 which is exactly what must not be labelled image/svg+xml and cached for a 

336 year. 

337 """ 

338 i = start 

339 while i < end: 

340 byte = content[i] 

341 if byte == _LT: 

342 return False 

343 if byte != _AMP: 

344 i += 1 

345 continue 

346 semicolon = content.find(b";", i + 1, end) 

347 if semicolon == -1 or not _is_reference_body(content[i + 1 : semicolon]): 

348 return False 

349 i = semicolon + 1 

350 return True

353def _completes_svg_start_tag(content: bytes, index: int) -> bool: 

354 """Whether the ``<svg`` ending at ``index`` is a complete start tag. 

355 

356 Parses XML's own productions rather than hunting for a delimiter:: 

357 

358 STag ::= '<' Name (S Attribute)* S? '>' 

359 EmptyElemTag ::= '<' Name (S Attribute)* S? '/>' 

360 Attribute ::= Name Eq AttValue 

361 Eq ::= S? '=' S? 

362 AttValue ::= '"' [^<&"]* '"' | "'" [^<&']* "'" 

363 

364 Deciding by delimiter is what kept failing: every review round found 

365 another byte that looks like the tag's end without being it — a ``>`` 

366 inside an attribute value, a ``<`` belonging to the NEXT element, a ``/`` 

367 that is not the one in ``/>``. Parsing the production leaves no such 

368 residue, and everything it rejects is a fatal XML error: a file no 

369 renderer would draw, which is exactly what must not be labelled 

370 ``image/svg+xml`` and cached for a year. 

371 

372 ``index`` points just past the element NAME, so this also decides that 

373 the name ends there rather than continuing (``<svgx…``). 

374 """ 

375 n = len(content) 

376 i = index 

377 if i >= n: 

378 return False # `<svg` and then nothing: an unclosed tag, not a root. 

379 byte = content[i] 

380 if byte == _GT: 380 ↛ 381line 380 didn't jump to line 381 because the condition on line 380 was never true

381 return True 

382 if byte == _SLASH: 

383 return content.startswith(b"/>", i) 

384 if byte not in _XML_SPACE: 

385 return False # `<svgx…`: a different element name. 

386 

387 while True: 

388 # `S` before an attribute is REQUIRED; before `>` or `/>` optional. 

389 separated_at = i 

390 while i < n and content[i] in _XML_SPACE: 

391 i += 1 

392 if i >= n: 

393 return False # the tag never closes 

394 byte = content[i] 

395 if byte == _GT: 

396 return True 

397 if byte == _SLASH: 

398 # A slash is legal only as the `/>` of an empty element: XML 

399 # allows nothing between it and the bracket, so `<svg /x>` and 

400 # `<svg / >` are tags that never close. 

401 return content.startswith(b"/>", i) 

402 if i == separated_at: 

403 return False # `<svg a="1"b="2">`: attributes need whitespace 

404 

405 # Attribute ::= Name Eq AttValue 

406 name_start = i 

407 while i < n and content[i] not in _ATTR_NAME_END: 

408 i += 1 

409 if i == name_start: 

410 return False # no name where an attribute must begin 

411 while i < n and content[i] in _XML_SPACE: 

412 i += 1 

413 if i >= n or content[i] != _EQUALS: 

414 return False 

415 i += 1 

416 while i < n and content[i] in _XML_SPACE: 

417 i += 1 

418 if i >= n or content[i] not in _QUOTE_BYTES: 

419 return False # an unquoted value is not an AttValue at all 

420 closing = content.find(content[i : i + 1], i + 1) 

421 if closing == -1: 

422 return False # unterminated literal 

423 if not _is_attribute_value(content, i + 1, closing): 

424 return False 

425 i = closing + 1

428def _has_svg_root(content: bytes) -> bool: 

429 """Whether ``content`` opens an ``<svg>`` root element. 

430 

431 Scans the WHOLE file — it is already in memory — skipping each prologue 

432 node by its own terminator, since every one of them can contain a ``>`` 

433 that is not its end: 

434 

435 * comment ``<!--`` … ``-->`` 

436 * PI / XML decl ``<?`` … ``?>`` (NOT the first ``>``: a pseudo 

437 attribute may hold one, e.g. ``<?xml-stylesheet href="a>b.css"?>``. 

438 PI content has no quote semantics, so it is never quote-tracked — 

439 doing so would trip over an apostrophe in prose.) 

440 * ``<!…>`` see `_end_of_markup_declaration` 

441 

442 Anything else before a root means this is not an SVG. 

443 

444 DECLARED BOUNDARIES. This establishes that an ``<svg>`` root element 

445 opens and closes; it is not a well-formedness check on the document, 

446 which is the renderer's business. A root reached through a namespace 

447 PREFIX (``<s:svg>``) is not recognised, nor is a UTF-16/32 encoded file — 

448 both are legal XML that no SVG tool emits, and both have always been 

449 rejected here. Attribute NAMES are not validated against XML's NameChar 

450 set either: a name's validity does not decide whether a root is present. 

451 """ 

452 i = 3 if content.startswith(b"\xef\xbb\xbf") else 0 

453 n = len(content) 

454 while True: 

455 while i < n and content[i] in _XML_SPACE: 

456 i += 1 

457 if content.startswith(b"<svg", i): 

458 return _completes_svg_start_tag(content, i + 4) 

459 if content.startswith(b"<!--", i): 

460 end = content.find(b"-->", i + 4) 

461 if end == -1: 

462 return False 

463 i = end + 3 

464 elif content.startswith(b"<?", i): 

465 end = content.find(b"?>", i + 2) 

466 if end == -1: 

467 return False 

468 i = end + 2 

469 elif content.startswith(b"<!", i): 

470 end = _end_of_markup_declaration(content, i + 2) 

471 if end is None: 

472 return False 

473 i = end 

474 else: 

475 return False

478def _sniff_logo_mime(content: bytes, path_label: str) -> str: 

479 """MIME from actual content (PNG/JPEG/WebP/SVG), not the extension.""" 

480 if content.startswith(b"\x89PNG\r\n\x1a\n"): 

481 return "image/png" 

482 if content.startswith(b"\xff\xd8\xff"): 482 ↛ 483line 482 didn't jump to line 483 because the condition on line 482 was never true

483 return "image/jpeg" 

484 if content[:4] == b"RIFF" and content[8:12] == b"WEBP": 484 ↛ 485line 484 didn't jump to line 485 because the condition on line 484 was never true

485 return "image/webp" 

486 # SVG requires an actual <svg> ROOT. An XML declaration, or leading 

487 # comments / doctype / processing instructions, may precede it — but a 

488 # file that merely *starts* like XML and never opens an <svg> element is 

489 # not an image, and accepting it would serve an unrenderable logo with an 

490 # immutable image/svg+xml cache header (and contradict the fail-fast 

491 # promise this function's error message makes). 

492 if _has_svg_root(content): 

493 return "image/svg+xml" 

494 raise UICustomizationError( 

495 f"logo {path_label!r}: content is not PNG, JPEG, WebP or SVG " 

496 "(MIME is checked against the actual bytes, not the extension)" 

497 )

915def resolve_ui_customization_snapshot( 

916 bundle_dir: str | Path, 

917) -> UICustomizationSnapshot | None: 

918 """Resolve a CONFIGURED ``UI_TEMPLATES_DIR`` into a snapshot, or ``None``. 

919 

920 Three states, deliberately kept distinct: 

921 

922 - **directory missing** → :class:`UICustomizationError`. Pointing the 

923 variable at nothing is a configuration error, and no deployment shape 

924 produces it by accident: a compose bind mount materializes both ends 

925 before the container starts, so this only ever fires on a typo. 

926 - **directory present, no ``manifest.json``** → ``None`` plus a caller-side 

927 warning. This is an unpopulated mount point — the state every default 

928 Docker deployment starts in, because the compose file mounts 

929 ``./data/ui_templates`` and sets the variable unconditionally so that 

930 dropping a bundle in and restarting is the whole activation procedure. 

931 Failing here would make the shipped compose files refuse to boot. 

932 Only a genuinely ABSENT path counts: a ``manifest.json`` that exists as 

933 a directory, a dangling symlink or any other non-regular file is an 

934 anomaly, not an empty mount point, and it raises rather than degrading 

935 to the built-in branding. 

936 - **``manifest.json`` present** → full validation, unchanged. Fail-fast 

937 still owns everything from here on: a partial, corrupt or half-copied 

938 bundle refuses startup rather than silently serving LightRAG content to 

939 an operator who believes their branding is live. 

940 

941 Emptiness is deliberately NOT judged by "the directory has no entries": 

942 a stray ``.DS_Store`` or ``.gitkeep`` — which macOS and git produce 

943 unbidden in exactly this directory — would then flip a working deployment 

944 into a boot loop. The manifest is the bundle's own entry point, so its 

945 absence is the honest test for "nothing to load yet". 

946 """ 

947 root = Path(bundle_dir) 

948 if not root.is_dir(): 

949 raise _fail(f"directory {str(root)!r} does not exist or is not a directory") 

950 manifest_path = root / BUNDLE_MANIFEST_NAME 

951 if not manifest_path.is_file(): 

952 # exists() follows symlinks, so a dangling one needs is_symlink() to be 

953 # told apart from nothing being there at all. 

954 if manifest_path.exists() or manifest_path.is_symlink(): 

955 raise _fail( 

956 f"{BUNDLE_MANIFEST_NAME} exists but is not a readable regular " 

957 "file (a directory, a broken symlink or similar)" 

958 ) 

959 return None 

960 return load_ui_customization_snapshot(root)
